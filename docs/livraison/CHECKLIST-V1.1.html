Checklist V1.1 — recette et production

Produit prêt pour la recette client. L’URL publique et les stores attendent le domaine, l’hébergement et les comptes Apple / Google (hors forfait).

Produit (fait)

  • Trois portails web : professeur, préfet, direction
  • 2FA obligatoire pour tout compte directeur
  • Isolation école / cycle / classe-matière
  • Inscription préfet + bulletin PDF + notif parent
  • Bilan du jour directeur (appel, personnel, perturbations)
  • Landing EduAdmins + login + menus
  • EduParent : communiqué, EDT, message, notes, absences, bulletins
  • Guides imprimables + 2 supports de formation

Recette client (à cocher ensemble)

  • Préfet collège : pas d’accès primaire
  • Professeur : seulement ses classes
  • Directeur : code 6 chiffres à chaque connexion
  • Communiqué direction → notification EduParent
  • Créneau EDT préfet → semaine EduParent
  • Message parent ↔ professeur des deux côtés

Avant URL de production (hors forfait hébergement)

  • Domaine + certificat HTTPS
  • PostgreSQL production + prisma migrate deploy
  • Variables : DATABASE_URL, NEXTAUTH_SECRET, NEXTAUTH_URL, JWT mobile
  • Envoi e-mail du code 2FA (aujourd’hui le code s’affiche en recette locale uniquement)
  • Comptes réels (plus @ecole.sn) et mot de passe directeur unique
