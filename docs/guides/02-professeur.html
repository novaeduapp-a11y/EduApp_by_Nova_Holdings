Guide professeur

Notes, appel, planning et messages — uniquement vos classes et vos matières. Ouverture dans le navigateur, pas d’application store.

1. Connexion

  1. Ouvrez le site de l’établissement.
  2. Choisissez le portail Professeurs.
  3. Connectez-vous avec l’e-mail fourni par la direction.

Un instituteur (primaire) voit toutes les matières de sa classe. Un professeur de matière ne voit que ses couples classe / matière.

2. Journée type

MenuÀ faireOù ça apparaît

NotesSaisir les notes d’une évaluation, puis enregistrerEduParent (Notes) · bilan trimestre Préfet
PlanningConsulter vos créneaux (saisis par le préfet)Identique côté parent
MessagerieRépondre aux parents de vos élèvesEduParent (Messages)
AlertesLire communiqués et messages parents—
Lien Mes classes Depuis une classe, ouvrez Appel ou Notes : la classe est déjà sélectionnée.

3. Règles

  • Vous ne voyez pas les autres écoles, ni les classes hors affectation.
  • Un instituteur ne voit pas le collège.
  • Marquer Présent à l’appel retire l’absence du jour pour cet élève.
Si une classe n’apparaît pas Le préfet doit affecter la matière (et vous) à cette classe. Sans affectation, pas d’appel, pas de notes, pas de message parent.
