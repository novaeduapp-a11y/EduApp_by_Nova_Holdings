Guide préfet

Inscriptions, classes, EDT, bulletins et communiqués de votre cycle uniquement : primaire, collège ou secondaire.

1. Connexion

Site de l’établissement → portail Préfets. Un préfet collège ne peut pas créer un CM1 ni voir les élèves du primaire.

2. Inscrire un élève

  1. Élèves → nouvel élève.
  2. Choisissez d’abord le niveau, puis la classe (effectif max respecté).
  3. Renseignez lieu, adresse, groupe sanguin, allergies.
  4. L’e-mail du parent est obligatoire : le compte parent est lié ou créé. Si création, un mot de passe à usage unique s’affiche : transmettez-le au parent.

3. Classes et EDT

  • Classes : affectez matière + professeur. Sans cela, le prof ne voit pas la classe et l’EDT n’a pas de matière.
  • Emploi du temps : grille lundi–vendredi. Les créneaux apparaissent dans EduParent et dans le planning du professeur.

4. Bulletins et communiqués

ActionEffet
Générer un bulletinPDF parent + notification EduParent
Publier un communiquéParents du cycle et/ou professeurs (alertes)
Bilan trimestreMoyennes et mentions issues des notes professeurs
Bulletin sans parent lié Le PDF se génère, mais aucun parent n’est notifié. Reliez un e-mail parent sur la fiche élève.
