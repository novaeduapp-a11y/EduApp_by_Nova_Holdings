Guide direction

Bilan du jour de votre établissement. Connexion protégée par un code à 6 chiffres, à chaque fois.

1. Connexion 2FA

  1. Portail Direction.
  2. E-mail et mot de passe.
  3. Saisissez le code à 6 chiffres (valable 10 minutes). En recette locale, le code s’affiche à l’écran ; en production, il est envoyé selon le paramétrage de l’hébergeur.

2. Bilan du jour (accueil)

C’est le tableau de bord. Les compteurs viennent d’ailleurs :

  • Absences / retards élèves — appel professeur
  • Absences / retards profs — saisie Personnel
  • Communiqués urgents et notes d’agenda du jour

Vous pouvez saisir une perturbation (coupure d’eau, etc.) : elle s’enregistre sur le bilan et notifie parents et professeurs. Seules les perturbations se retirent ici, pas les absences du personnel.

3. Autres menus

MenuUsage
AperçuEffectifs, moyenne de la période active, présence du jour (hors retards)
PersonnelPrésent / retard / absent — visible ensuite sur le bilan
CommuniquésEnvoi établissement (tous cycles) → EduParent et alertes profs
AgendaRappels internes, pas une messagerie. Les notes du jour remontent au bilan
Isolation Vous voyez les trois cycles de votre école, jamais une autre école.

4. Compte démo (recette)

Directeur directeur@ecole.sn · 2FA obligatoire.
Mot de passe commun de démo (fourni à la formation).
