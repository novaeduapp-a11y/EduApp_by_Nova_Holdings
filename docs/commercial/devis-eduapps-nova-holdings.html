01

Contexte & périmètre

Le présent document constitue la proposition commerciale finale entre Khidma Service Digital et NOVA HOLDINGS, pour la mise en production de la suite EduApps (EduParent + EduAdmins), alignée sur le cahier des charges v1.0 et adaptée au budget convenu.

Forfait global 3 000 000 FCFA Paiement 30 % · 30 % · 40 % Maintenance : contrat séparé après livraison

Deux applications distinctes, architecture de données commune, isolation par rôle / cycle / établissement, en s’appuyant sur le socle déjà présenté pour accélérer et réduire le coût.

03

Lot A — Socle existant (plateforme présentée)

Cession / intégration de la plateforme déjà présentée

450 000 FCFA

Remise et intégration du code de la solution déjà démontrée comme base technique du projet EduApps (élèves, notes, bulletins QR, absences, espaces par rôle, auth).

Inclus

  • Code source de la plateforme web actuelle
  • Schéma / base de données et documentation de démarrage
  • 1 déploiement initial + formation de base (~2 h)
  • Correction des bugs bloquants liés à la livraison (30 jours)
  • Droit d’usage pour NOVA HOLDINGS / établissements partenaires
Inclus Code · déploiement · formation 2 h · accélérateur pour Lots B & C
Non inclus Hébergement · nom de domaine · revente tierce sans avenant · support illimité après 30 jours

Ce lot permet de réduire le coût global : le backend et une partie des modules métier sont déjà en place, au lieu de tout reconstruire.

05

Lot C — EduAdmins (mobile + web)

Profs · Préfets · Direction — Mobile & Ordinateur

1 450 000 FCFA

Plateforme de gestion pour le personnel, avec trois portails distincts et version web desktop (landing + sidebar), conforme CDC §4–5. Inclut les adaptations backend nécessaires (multi-cycles, multi-écoles, 2FA Direction, API étendue) à partir du Lot A.

Authentification (CDC §4.2)

  • Portail Professeurs · Portail Préfets · Portail Direction
  • 2FA (code 6 chiffres) pour le portail Direction
  • Sélection d’établissement (recherche multi-écoles partenaires)

Portail Professeurs

  • Professeur de matière : planning, présences, saisie notes, messagerie, alertes — uniquement ses classes / sa matière
  • Instituteur primaire : toutes les matières de sa classe — isolation primaire / collège / secondaire

Portail Préfets (3 cycles)

  • Inscription élèves (tuteur, médical, niveau) — cycle du préfet uniquement
  • Gestion des classes, affectations, capacité, professeur principal
  • Bulletins (moyennes coefficients, appréciations, impression)
  • Communiqués (destinataires, urgence, historique)
  • Bilan bulletin par classe / trimestre

Portail Direction

  • Bilan du jour (absences élèves & profs, retards, perturbations)
  • Aperçu général (stats établissement)
  • Alertes / communiqués, gestion personnel, agenda institutionnel

Site web EduAdmins

  • Landing marketing (héros, 3 portails, « comment ça marche », sécurité, footer NOVA)
  • Sélection école + interface desktop à barre latérale
  • Parité fonctionnelle avec le mobile (adaptée grand écran)

Livrables

  • App mobile EduAdmins + site web responsive
  • Comptes de démonstration par profil
  • Guides courts : Prof / Préfet / Direction
  • 2 sessions de formation (référents NOVA + établissement pilote)

09

Maintenance (contrat ultérieur)

Conformément à l’accord des parties, la maintenance n’est pas incluse dans le forfait de 3 000 000 FCFA.

  • Un contrat de maintenance sera proposé et signé après la livraison / recette
  • Il couvrira typiquement : correctifs, petites évolutions, support, mises à jour de sécurité
  • Indication tarifaire (à formaliser) : 100 000 – 150 000 FCFA / mois selon le niveau de service

La garantie bugs bloquants (60 jours après recette) reste incluse dans le présent forfait. Au-delà : contrat de maintenance.
