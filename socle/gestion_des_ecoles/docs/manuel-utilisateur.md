# 📖 Manuel Utilisateur - SchoolGest

## Guide Complet pour les Utilisateurs

---

# PARTIE 1 : ESPACE ADMINISTRATION

## Chapitre 1 : Tableau de Bord

Le tableau de bord affiche un résumé de votre établissement :

- **Nombre total d'élèves**
- **Nombre de classes**
- **Nombre de professeurs**
- **Statistiques des paiements**
- **Graphiques de répartition**

---

## Chapitre 2 : Gestion des Élèves

### 2.1 Ajouter un Élève

1. Cliquer sur **Élèves** dans le menu
2. Cliquer sur **+ Nouvel élève**
3. Remplir le formulaire :
   - **Nom** (obligatoire)
   - **Prénom** (obligatoire)
   - **Date de naissance** (obligatoire)
   - **Sexe** (M/F)
   - **Classe** (sélectionner)
   - **Informations parents** (optionnel)
4. Cocher **"Créer un compte utilisateur"** si l'élève doit pouvoir se connecter
5. Cliquer sur **Enregistrer**

> 💡 **Astuce** : Si vous créez un compte, notez bien le matricule et mot de passe affichés !

### 2.2 Importer des Élèves (Excel)

1. Cliquer sur **Import/Export**
2. Télécharger le **modèle Excel**
3. Remplir le fichier avec vos données
4. Importer le fichier complété

### 2.3 Modifier un Élève

1. Trouver l'élève dans la liste
2. Cliquer sur l'icône **crayon** (modifier)
3. Modifier les informations
4. Cliquer sur **Enregistrer**

### 2.4 Supprimer un Élève

1. Trouver l'élève dans la liste
2. Cliquer sur l'icône **corbeille**
3. Confirmer la suppression

> ⚠️ **Attention** : La suppression est irréversible !

---

## Chapitre 3 : Gestion des Classes

### 3.1 Créer une Classe

1. Aller dans **Classes**
2. Cliquer sur **+ Nouvelle classe**
3. Remplir :
   - **Nom** (ex: 6ème A)
   - **Niveau** (ex: 6ème)
   - **Année scolaire** (ex: 2025-2026)
   - **Effectif maximum**
4. Cliquer sur **Créer**

### 3.2 Attribuer des Matières

1. Ouvrir une classe
2. Aller dans l'onglet **Matières**
3. Cocher les matières enseignées
4. Définir les coefficients
5. Enregistrer

---

## Chapitre 4 : Gestion des Matières

### 4.1 Créer une Matière

1. Aller dans **Matières**
2. Cliquer sur **+ Nouvelle matière**
3. Remplir :
   - **Nom** (ex: Mathématiques)
   - **Code** (ex: MATH)
   - **Coefficient** (ex: 4)
   - **Couleur** (optionnel)
4. Cliquer sur **Créer**

---

## Chapitre 5 : Saisie des Notes

### 5.1 Créer une Évaluation

1. Aller dans **Notes** > **Saisie**
2. Sélectionner :
   - **Classe**
   - **Matière**
   - **Période** (trimestre)
3. Cliquer sur **+ Nouvelle évaluation**
4. Remplir :
   - **Titre** (ex: Devoir n°1)
   - **Type** (Devoir, Composition, Interrogation, TP)
   - **Date**
   - **Note sur** (ex: 20)
   - **Coefficient** (ex: 1)
5. Cliquer sur **Créer**

### 5.2 Saisir les Notes

1. Sélectionner l'évaluation
2. Pour chaque élève :
   - Entrer la note
   - Ou cocher **Absent** si absent
3. Cliquer sur **Enregistrer**

### 5.3 Calculer les Moyennes

1. Aller dans **Notes** > **Moyennes**
2. Sélectionner la classe et la période
3. Cliquer sur **Calculer les moyennes**
4. Les moyennes et rangs sont calculés automatiquement

---

## Chapitre 6 : Génération des Bulletins

### 6.1 Générer un Bulletin

1. Aller dans **Bulletins** > **Générer**
2. Sélectionner :
   - **Classe**
   - **Période**
3. Cocher les élèves concernés
4. Cliquer sur **Générer**
5. Les bulletins PDF sont créés avec QR Code

### 6.2 Télécharger un Bulletin

1. Aller dans **Bulletins**
2. Trouver le bulletin
3. Cliquer sur **Télécharger PDF**

### 6.3 Vérifier un Bulletin

1. Scanner le QR Code avec un téléphone
2. La page de vérification s'affiche
3. Comparer les informations avec le bulletin papier

---

## Chapitre 7 : Gestion des Absences

### 7.1 Enregistrer une Absence

1. Aller dans **Absences** > **Nouveau**
2. Sélectionner :
   - **Élève**
   - **Date**
   - **Période** (Matin, Après-midi, Journée)
   - **Matière** (optionnel)
3. Cocher **Justifiée** si applicable
4. Ajouter un **motif**
5. Cliquer sur **Enregistrer**

---

## Chapitre 8 : Gestion des Paiements

### 8.1 Créer un Paiement

1. Aller dans **Paiements**
2. Cliquer sur **+ Nouveau paiement**
3. Sélectionner :
   - **Élève**
   - **Type de frais** (Inscription, Scolarité, etc.)
   - **Montant total**
   - **Échéance**
4. Cliquer sur **Créer**

### 8.2 Enregistrer un Versement

1. Trouver le paiement
2. Cliquer sur **+ Versement**
3. Entrer :
   - **Montant**
   - **Date**
   - **Mode de paiement** (Espèces, Wave, Orange Money)
4. Cliquer sur **Enregistrer**

---

## Chapitre 9 : Gestion des Utilisateurs

### 9.1 Créer un Utilisateur

1. Aller dans **Utilisateurs**
2. Cliquer sur **+ Nouvel utilisateur**
3. Remplir :
   - **Nom, Prénom**
   - **Email**
   - **Rôle** (Admin, Directeur, Professeur)
   - **Mot de passe**
4. Cliquer sur **Créer**

---

## Chapitre 10 : Gestion des Parents

### 10.1 Créer un Compte Parent

1. Aller dans **Parents**
2. Cliquer sur **+ Nouveau parent**
3. Entrer l'**email** ou **téléphone**
   - Le système détecte automatiquement les enfants
   - Les informations sont auto-remplies si disponibles
4. Définir un **mot de passe**
5. Cliquer sur **Créer**

---

# PARTIE 2 : ESPACE PARENT

## Chapitre 11 : Accès Parent

### 11.1 Se Connecter

1. Aller sur la page de connexion
2. Entrer votre **email** ou **téléphone**
3. Entrer votre **mot de passe**
4. Cliquer sur **Se connecter**

### 11.2 Consulter les Notes

1. Sélectionner un enfant
2. Cliquer sur **Notes**
3. Les notes s'affichent par matière

### 11.3 Télécharger un Bulletin

1. Sélectionner un enfant
2. Cliquer sur **Bulletins**
3. Cliquer sur **Télécharger** pour le trimestre souhaité

### 11.4 Voir les Absences

1. Sélectionner un enfant
2. Cliquer sur **Absences**
3. L'historique des absences s'affiche

## Chapitre 13 : Accès Professeur

### 13.1 Se Connecter

# ANNEXES

## A. Raccourcis Clavier

| Raccourci | Action |
|-----------|--------|
| `Ctrl + S` | Enregistrer |
| `Échap` | Fermer le dialogue |
| `Tab` | Champ suivant |

## B. Formats de Fichiers

| Type | Format accepté |
|------|----------------|
| Import élèves | .xlsx, .xls |
| Export | .xlsx, .pdf |
| Photos | .jpg, .png |

## C. Glossaire

| Terme | Définition |
|-------|------------|
| **Matricule** | Identifiant unique de l'élève |
| **Période** | Trimestre ou semestre |
| **Coefficient** | Poids de la matière dans la moyenne |
| **QR Code** | Code de vérification du bulletin |
